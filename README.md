# Удаление кодов из Excel по PDF

Веб-инструмент для массового удаления строк из Excel-файла по кодам с QR-этикеток.

**Как это работает в двух словах:** в Excel есть столбец «Код» (например,
`0104699132224017215FzCJZuo6Ywt*`). В PDF под каждым QR-кодом напечатан тот же код (разбитый
на две строки) и номер этикетки (например, №485). Инструмент извлекает коды из PDF, оставляет
только те, чьи номера попадают в указанный диапазон, находит их в Excel и удаляет эти строки.
Результат скачивается готовым .xlsx файлом.

## Использование

1. Откройте сайт (после включения GitHub Pages: `https://rzhavezubilo.github.io/excel_pdf_search_delete/`).
2. Загрузите Excel-файл (.xlsx) — лист определяется автоматически по столбцу «Код».
3. Загрузите один или несколько PDF с этикетками.
4. Для каждого PDF укажите, коды с какими номерами удалять:
   - `485` — с №485 до конца;
   - `456-500` — диапазон;
   - пусто — все коды из этого PDF.
   Поддерживается префикс «с»/«от» («с 485») и длинное тире.
5. Нажмите «Удалить строки и скачать Excel» — скачается файл `<имя>_обновленный.xlsx`.

Перед скачиванием показывается сводка: сколько кодов выбрано, сколько найдено в Excel
и сколько не найдено (они не удаляются, а выводятся предупреждением).

## Приватность

Всё работает **локально в браузере** — файлы никуда не отправляются. Сайт статический,
серверной части нет.

## Формат этикеток

Парсер ищет на каждой странице PDF:
- строку с номером этикетки: `№123`;
- код: строка из 16 цифр, начинающаяся с `01` (GS1 AI 01 + GTIN), за которой следует строка,
  начинающаяся с `21` (AI 21 + серийный номер) — либо весь код одной строкой.

Код собирается конкатенацией двух строк: `0104699132224017` + `215FzCJZuo6Ywt*`
→ `0104699132224017215FzCJZuo6Ywt*` — именно в таком виде код лежит в столбце «Код».

## Технические детали

- Чистый статический сайт: без сборки и зависимостей времени разработки.
- [pdf.js](https://github.com/mozilla/pdf.js) 3.11.174 — извлечение текста из PDF
  (библиотеки лежат локально в `vendor/`, сайт работает автономно).
- [ExcelJS](https://github.com/exceljs/exceljs) 4.4.0 — чтение/запись .xlsx с сохранением
  форматирования; строки удаляются через `spliceRows` снизу вверх.
- Файл для скачивания формируется заново из исходного Excel при каждом нажатии кнопки,
  поэтому диапазоны можно менять и скачивать результат повторно.

## Запуск локально

Из-за веб-воркера pdf.js страницу нужно открывать по HTTP, а не как `file://`:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```
